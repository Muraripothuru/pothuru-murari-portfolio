SOC282 — Phishing Alert: Deceptive Mail Detected
Let's Defend Platform · Event ID 257 · 2024-05-13
Phishing AsyncRAT T1566

[ DETECTION & ANALYSIS ]

  • Suspicious email from free@coffeeshoop.com (SMTP: 103.80.134.63) to user "Felix"
  • Subject: "Free Coffee Voucher" with urgency tactics ("Hurry", "Expires soon")
  • Contained malicious URL → VirusTotal: 3 engines flagged, categorized as silent builder

[ CONTAINMENT & RESPONSE ]

  • Email was delivered (device action: allowed) — user opened the attachment
  • coffee.exe executed and connected to C2: 37.120.233.226
  • Isolated host Felix (172.16.20.151) via endpoint security
  • Deleted phishing email from mailbox, recommended credential reset & user training
✓ FINAL VERDICT — TRUE POSITIVE · COMPROMISED
